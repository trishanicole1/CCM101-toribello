Guide Questions

1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS is generally considered to offer the broadest range of cloud services. It provides hundreds of products covering compute, storage, databases, machine learning, IoT, security, networking, and many other areas. As one of the earliest major cloud providers, AWS has had more time to expand its service catalog and develop specialized cloud solutions.

2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

Microsoft Azure would be the best choice for an organization that primarily uses Microsoft products. Azure integrates closely with services such as Active Directory, Windows Server, Microsoft 365, and .NET applications. This integration can help reduce compatibility issues and simplify management and licensing for organizations already using the Microsoft ecosystem.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its strengths in Artificial Intelligence, Machine Learning, and Kubernetes services. Google originally developed Kubernetes and provides Google Kubernetes Engine (GKE), a leading managed Kubernetes platform. Google Cloud also offers AI and ML tools such as Vertex AI, which provide a wide range of capabilities for developing and deploying intelligent applications.

4. What similarities did you observe among the three cloud providers?

All three major cloud providers offer similar core infrastructure services, including scalable compute resources, object or blob storage, virtual networking, and identity and access management. They also support pay-as-you-go pricing models, provide data centers across multiple global regions, and offer technologies for infrastructure as code, containers, hybrid cloud, and multi-cloud deployments.
