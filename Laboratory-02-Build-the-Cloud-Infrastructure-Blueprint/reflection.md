
Mission Reflection

1. Which cloud infrastructure component do you think is the most important? Why?

I believe compute is the most important component because it provides the processing power needed to run applications and perform tasks. Storage is responsible for keeping data, while networking allows systems to communicate, but compute is what processes information and responds to requests. However, all infrastructure components work together as a complete system. Compute depends on storage for data and networking for communication, so each component plays an important role.

2. How does Linux support cloud computing?

Linux supports cloud computing because it is open-source, lightweight, stable, and efficient to operate at scale. Major cloud providers such as AWS, Microsoft Azure, and Google Cloud Platform offer Linux-based virtual machines and container environments. Linux also provides powerful command-line tools that support automation, system administration, and troubleshooting. During this laboratory activity, I used commands such as lscpu, free -h, and ip a to quickly collect information about the server.

3. Why is technical documentation important before deploying infrastructure?

Technical documentation helps engineers understand what resources are available, how they are configured, and how the different components work together before making changes. Proper documentation reduces confusion, improves consistency, and makes troubleshooting easier. It also allows other engineers or future team members to understand the project without having to repeat the entire investigation process.

4. What new skills did you learn during this laboratory activity?

I learned how to investigate the hardware and software resources of a Linux server using terminal commands. I also learned how to connect these findings to cloud infrastructure concepts and compare equivalent services offered by AWS, Microsoft Azure, and Google Cloud Platform. In addition, I improved my Git and GitHub skills by troubleshooting issues such as missing Git identity configuration and authentication using a Personal Access Token.

5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio now includes a more advanced laboratory activity with organized Markdown documentation, a comparison of major cloud providers, an infrastructure report, and a cloud architecture diagram. This project demonstrates not only my understanding of cloud computing concepts but also my ability to investigate a real Linux environment, organize technical information, and document my work professionally.
