# Laboratory Activity 1 – Mission 1: Welcome to the Cloud

## Mission Overview

This laboratory activity focused on the onboarding process of a **Junior Cloud Infrastructure Engineer Trainee** at **CloudNova Technologies**. The activity provided hands-on experience with a Linux-based cloud environment, basic system administration, file organization, and professional technical documentation. It also introduced the use of Git and GitHub for managing and maintaining a cloud computing portfolio.

## Objectives

* Access and use a cloud-based Linux environment through KillerCoda
* Navigate and perform basic operations within the Linux operating system
* Collect and analyze basic system information
* Create and organize files and directories using Linux commands
* Practice basic user and privilege management
* Create and maintain a professional GitHub repository
* Document technical activities using Markdown
* Apply basic Git commands for version control

## Activities Performed

* Launched an Ubuntu Linux Playground using KillerCoda
* Created a user account with sudo privileges and accessed the Linux environment
* Verified the current username, working directory, and system hostname
* Collected system information, including the Linux distribution, kernel version, CPU, memory, and available disk space
* Created an organized directory structure consisting of **Documents, Notes, Reports, and Screenshots**
* Created and edited Markdown files such as **about-me.md** and **system-information.md**
* Created and organized a public GitHub repository as a **Cloud Computing Portfolio**
* Used Git to track changes and manage files within the repository
* Documented the completed laboratory activity using Markdown

## Linux Commands Used

The following Linux and Git commands were practiced during the activity:

`whoami`, `pwd`, `hostname`, `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`, `mkdir`, `nano`, `cat`, `ls`, `git clone`, `git add`, `git commit`, and `git push`

## Skills Learned

Through this laboratory activity, I developed the following skills:

* Basic Linux navigation and command-line operations
* System information gathering and monitoring
* User account creation and sudo privilege management
* File and directory organization
* Markdown-based technical documentation
* Basic Git version control
* GitHub repository management and organization
* Professional documentation of technical activities

## Conclusion

This laboratory activity provided a strong introduction to the tools and practices used in cloud infrastructure environments. By working with Linux, Git, and GitHub, I gained practical experience in managing a cloud-based system and documenting technical tasks. These skills will serve as a foundation for future cloud computing activities and my development as a Junior Cloud Infrastructure Engineer Trainee.
