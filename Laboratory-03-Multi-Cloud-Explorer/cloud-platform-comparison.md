# Cloud Platform Comparison

## Checkpoint 3 – Core Comparison Table

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | EC2 (Elastic Compute Cloud) | Azure Virtual Machines | Compute Engine |
| Storage Service | S3 (Simple Storage Service) | Blob Storage | Cloud Storage |
| Networking Service | VPC (Virtual Private Cloud) | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity Service | IAM (Identity and Access Management) | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |
| Primary Strength | Broad service catalog, mature ecosystem, and strong global infrastructure | Deep integration with Microsoft enterprise technologies such as Microsoft 365, Windows Server, and Entra ID | Strong data analytics, AI/ML, Kubernetes, and cloud-native technologies |
| Ideal Organizations | Startups to large enterprises needing flexibility and a wide variety of cloud services | Enterprises already invested in the Microsoft technology ecosystem | Data-driven companies, AI/ML teams, and cloud-native organizations |

### Q1: Which cloud provider offers the broadest range of services?

**Answer:** AWS generally offers the broadest range of cloud services among the three major providers. It launched in 2006 and has continuously expanded its service catalog to support computing, storage, databases, networking, security, analytics, AI, machine learning, and many specialized workloads. This makes AWS a flexible choice for organizations with different technical requirements.

### Q2: Which provider best integrates with Microsoft technologies?

**Answer:** Microsoft Azure provides the strongest integration with Microsoft technologies because it is developed and operated by Microsoft. Azure integrates closely with services such as Microsoft Entra ID, Microsoft 365, Windows Server, SQL Server, and .NET, making it especially suitable for organizations that already use Microsoft's software ecosystem.

### Q3: Which provider is strongest in Artificial Intelligence and Kubernetes?

**Answer:** Google Cloud Platform is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes. Google originally developed Kubernetes internally, and Google Kubernetes Engine (GKE) provides a mature managed Kubernetes platform. GCP also offers powerful AI and machine learning tools, including Vertex AI, making it a strong option for AI-focused and cloud-native workloads.

### Q4: Which cloud platform would you personally choose and why?

**Answer:** I would personally choose AWS because it provides a broad selection of services and gives me flexibility when building different types of applications and cloud environments. Its mature ecosystem and wide range of computing, storage, networking, security, and database services would make it easier to start with a simple project and scale it as requirements grow.

## Overall Comparison

AWS, Microsoft Azure, and Google Cloud Platform are all powerful cloud computing platforms, but each has different strengths. AWS is a strong choice for organizations that need a broad service catalog and maximum flexibility, Azure is ideal for organizations heavily invested in Microsoft technologies, and GCP is particularly attractive for data analytics, artificial intelligence, machine learning, and Kubernetes workloads.

The best cloud provider ultimately depends on an organization's existing technology, budget, technical requirements, and long-term goals. There is no single provider that is best for every organization, which is why understanding the strengths and weaknesses of each platform is important when making a cloud adoption decision.
