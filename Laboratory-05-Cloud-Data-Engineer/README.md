# Laboratory 05 - Cloud Data Engineer

## Mission Overview
Deployed an S3-compatible object storage server (MinIO/SILO) using Docker to support a photo-sharing app's need for scalable storage of user-uploaded images.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy an Object Storage server using Docker
- Access the service via port forwarding
- Create a bucket and upload a file
- Document the process in Markdown

## Tools Used
- Docker
- MinIO / SILO (pgsty/minio)
- KillerCoda Ubuntu Playground
- GitHub

## Skills Learned
- Deploying containerized services with environment variables
- Understanding object storage vs. block/file storage
- Using port forwarding to access web-based services
- Adapting when an official Docker image becomes unavailable
- Writing clear technical Markdown documentation
